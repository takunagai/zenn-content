## MCP サーバーとは

MCP（Model Context Protocol）は、AI アプリケーションと外部サービスを「USB-C のように」つなぐ共通規格です。従来は API の仕様を理解し、クエリを書き、レスポンスを解析する必要がありました。MCP サーバーを経由すると、自然言語で話しかけるだけでデータを取得できます。MCP の概要と導入方法は[シリーズ #1](./mcp-server-tutorial-01-install) にまとめています。

## 国土交通データプラットフォームで使えるデータ

| 分野 | データの例 |
|---|---|
| 道路・構造物 | 道路・橋梁・トンネルの点検データ、交通量調査データ |
| 都市 | PLATEAU（3D 都市モデル）、都市計画・用途地域データ |
| 水・防災 | 河川・ダム・水資源データ、洪水浸水想定区域、土砂災害警戒区域 |
| 港湾・空港 | 港湾・空港のインフラデータ |
| 地盤 | 地質・ボーリングデータ |
| 人の動き | 旅客動態・観光データ |

## 利用条件について

データの利用条件は、プラットフォームの利用規約と、連携元のデータごとの条件の両方で決まります。出典の表示が求められるものが多いので、業務や公開物に使う前に、サイトの利用規約と、各データの詳細画面に書かれた条件を確認してください。

## 使い方のコツ

### 位置の指定は自然言語で通じる

`札幌テレビ塔の近くにどんなデータがあるか教えて` のように住所や施設名で指定すると、AI が緯度経度に直して、地点と半径で検索するツール（`search_by_location_point_distance`）を呼び出します。

### あいまいな検索にも対応している

`災害に関するデータ` のようなあいまいな指示でも、AI がキーワードを補いながら、該当しそうなデータを探します。

### 先に件数を確かめる

条件が広いと結果が大量になり、AI のコンテキストを圧迫します。`まず該当件数だけ教えて` と頼むと、件数の取得（`get_count_data`）で規模を確かめてから絞り込めます。

### 条件の追加と絞り込み

一度結果を見てから、`さらに○○で絞り込んで` と条件を足していけます。

### ダウンロード URL の取得

`ファイルの URL を教えて` と頼むとダウンロード用の URL を取得できます。URL の有効期限は 60 秒なので、表示されたらすぐに開きます。

## 提供されるツール

公開されているサーバーは α 版で、18 個のツールがあります。主なものは次のとおりです。

| 分類 | ツール |
|---|---|
| 検索 | `search`（キーワード）、`search_by_attribute`（都道府県・市区町村・データセットなどの属性）、`search_by_location_rectangle`（矩形範囲）、`search_by_location_point_distance`（地点と半径）、`get_mesh`（メッシュ） |
| データの取得 | `get_data`、`get_data_summary`、`get_data_catalog`、`get_all_data`、`get_count_data` |
| ファイル | `get_file_download_urls`、`get_zipfile_download_url`、`get_thumbnail_urls` |
| 補助 | `get_suggest`、`get_prefecture_data`、`get_municipality_data`、`normalize_codes` |

## セットアップ方法

Python 3.10 以降が必要です。リポジトリをクローンして、仮想環境の中で動かします。

### API キーの取得

[国土交通データプラットフォーム](https://data-platform.mlit.go.jp/)でアカウントを作成し、API キーを取得します。手順は[公式の API ドキュメント](https://data-platform.mlit.go.jp/api_docs/usage/introduction.html)にあります。

### インストール

```bash
git clone https://github.com/MLIT-DATA-PLATFORM/mlit-dpf-mcp.git
cd mlit-dpf-mcp

python -m venv .venv
source .venv/bin/activate   # Windows は .venv\Scripts\activate

pip install -e .
pip install aiohttp pydantic tenacity python-json-logger mcp python-dotenv
```

### Claude Desktop

設定ファイル（開き方は[シリーズ #1](./mcp-server-tutorial-01-install) を参照）に次を追加し、Claude Desktop を再起動します。`command` と `args` は、クローンした場所に合わせた絶対パスにします。

```json
{
  "mcpServers": {
    "mlit-dpf-mcp": {
      "command": "/Users/yourname/tools/mlit-dpf-mcp/.venv/bin/python",
      "args": ["/Users/yourname/tools/mlit-dpf-mcp/src/server.py"],
      "env": {
        "MLIT_API_KEY": "your_api_key_here",
        "MLIT_BASE_URL": "https://data-platform.mlit.go.jp/api/v1/",
        "PYTHONUNBUFFERED": "1",
        "LOG_LEVEL": "WARNING"
      }
    }
  }
}
```

Windows の場合、`command` は `.venv\Scripts\python.exe` のパスになります。

### Claude Code・Codex

```bash
claude mcp add mlit-dpf-mcp \
  -e MLIT_API_KEY=your_api_key_here \
  -e MLIT_BASE_URL=https://data-platform.mlit.go.jp/api/v1/ \
  -- /Users/yourname/tools/mlit-dpf-mcp/.venv/bin/python /Users/yourname/tools/mlit-dpf-mcp/src/server.py
```

```bash
codex mcp add mlit-dpf-mcp \
  --env MLIT_API_KEY=your_api_key_here \
  --env MLIT_BASE_URL=https://data-platform.mlit.go.jp/api/v1/ \
  -- /Users/yourname/tools/mlit-dpf-mcp/.venv/bin/python /Users/yourname/tools/mlit-dpf-mcp/src/server.py
```

API キーは設定に平文で残ります。AI とのチャット欄には貼らないでください。

## 地理空間 MCP Server も公開されている

国土交通省は、このサーバーとは別に「[地理空間 MCP Server（α 版）](https://www.mlit.go.jp/tochi_fudousan_kensetsugyo/tochi_fudousan_kensetsugyo_fr17_000001_00047.html)」も公開しています。「不動産情報ライブラリ」の API を使い、不動産の取引価格や、防災・都市計画に関する地理空間データを AI から扱えるようにするものです。不動産や地域分析が目的なら、こちらも候補になります。α 版で動作保証はなく、利用前に不動産情報ライブラリの利用約款を確認する必要があります。

## まとめ

国土交通省の MCP サーバーの公開は、日本のオープンデータ活用にとって大きな一歩です。

これまで、建設 DX や地域分析では「データにたどり着けない」ことがボトルネックになっていました。MCP サーバーがあれば、API の知識がなくても自然言語でデータにアクセスできます。一方で、どちらのサーバーもまだ α 版です。取得した数値を意思決定に使うときは、元のデータの定義と更新時期を確認してください。

e-Stat など他のオープンデータにも MCP 対応が広がれば、AI とオープンデータを組み合わせた分析は、さらに身近になっていくはずです。
